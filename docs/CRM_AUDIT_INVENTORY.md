# SAKK Group CRM — Audit Inventory (Evidence-Based)
Generated by live repository + database inspection during this audit. No secrets are recorded; only env var names.

## Stack discovered
- Frontend/Backend: Next.js 16.2.6 App Router (React 19.2.6) — UI and Route Handlers in one app (`src/app/page.tsx`, `src/app/api/**/route.ts`)
- Language: TypeScript 5.9 (strict), Tailwind CSS 4
- DB: PostgreSQL via Drizzle ORM 0.45.2 (`src/db/schema.ts`, `src/db/index.ts`, pool from `DATABASE_URL`)
- Auth: bcryptjs password hashing + HMAC-signed HttpOnly cookie (`src/lib/auth.ts`, cookie `nexus_session`, 7d)
- Env vars required: `DATABASE_URL` (present), `AUTH_SECRET` (optional/fallback existed — hardened in this audit)
- Redis: NOT present (no dependency, no config) — documented as not applicable; PostgreSQL is source of truth. No background queue exists.
- Tests before audit: none. Migrations: `drizzle-kit push` used (no migration files). Docker/CI: none found.

## Modules/pages before audit
Dashboard, Contacts, Companies, Deals, Pipeline (Kanban), Activities, Products, Invoices, Reports, Team, Settings — all in single-page shell `src/app/page.tsx` calling `/api/*` via `src/lib/api.ts`.

## API endpoints before audit (22)
auth/register, auth/login, auth/logout, auth/me (GET/PUT), contacts (+[id]), companies (+[id]), deals (+[id] incl PATCH stage), activities (+[id]), products (+[id]), invoices (+[id]), team (+[id]), dashboard, reports, export (CSV), health.

## DB tables before audit (7, verified via \dt)
users, companies, contacts, deals, activities, products, invoices. FKs: contacts/deals/activities/invoices -> companies/contacts/users/products with set-null/cascade as in schema. Money = decimal(15,2). No payments/allocations, quotations, contracts, projects, expenses, vendors, documents, notifications, audit logs, settings, invoice/quotation line-item tables.

## Gaps found on inspection (pre-fix)
- No RBAC enforcement: any authenticated role could manage team/delete records (frontend-only implication).
- Public registration allowed caller-chosen `admin` role (privilege escalation after first user).
- No auth rate limiting; no security headers in `next.config.ts`.
- Invoices: single amount*qty, no line items, no payments, no outstanding/partial/refund/credit-note model — "paid" was a manual status flag.
- Missing modules: Quotations, Contracts, Projects/Tasks, Vendors, Expenses/Procurement, Payments/Receivables & allocations, Credit Notes, Documents, Notifications, Audit Logs, Settings store, Lead conversion endpoint.
- No automated tests, no duplicate-contact detection, paid invoices freely editable, no audit trail.
- Dashboard/reports did not reconcile receivables/payments/expenses/projects.

## Modules added/hardened in this audit (see CRM_FEATURE_STATUS.md for verified status)
Quotations (+items, convert), Contracts, Projects + Project Tasks, Vendors, Expenses (approval workflow), Payments + Allocations (transactional), Credit Notes, Documents (metadata/URL registry), Notifications, Audit Logs, App Settings, RBAC, rate limiting, security headers, finance regression test script (`scripts/finance-regression.mjs`).
External email/PDF/payment-gateway/Redis queue: BLOCKED/NOT APPLICABLE — no credentials/provider in repo; recorded in production readiness doc, not faked.
